# English-to-Tamil Translation Web App

A simple Flask web application that translates English text into Tamil using the Hugging Face `facebook/nllb-200-distilled-600M` model. The repository also includes a Jupyter notebook (`translation(1).ipynb`) for testing the translation model independently.

## Features

- Translate English text into Tamil.
- Use the NLLB-200 distilled multilingual translation model.
- Return the translation as JSON from a Flask API endpoint.
- Test the model in a Jupyter notebook before running the web app.

## Requirements

- Python 3.10 or another Python version supported by the selected PyTorch and Transformers releases
- pip
- Internet access the first time the model is loaded, so Hugging Face can download the model files

## Installation

1. Open a terminal in the project folder.
2. Create and activate a virtual environment.

   **Windows PowerShell**
   ```powershell
   py -3.10 -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

   **Windows Command Prompt**
   ```bat
   py -3.10 -m venv .venv
   .venv\Scripts\activate.bat
   ```

3. Install the dependencies used by the Flask app and notebook:

   ```bash
   python -m pip install --upgrade pip
   python -m pip install Flask transformers==4.46.3 sentencepiece accelerate torch
   ```

   The notebook also installs `transformers==4.46.3`, `sentencepiece`, and `accelerate`. Keeping the Transformers version pinned helps the notebook and app use the same API.

## Run the Flask application

If your Python file is currently named `app(5).py`, rename it to `app.py` (recommended), then run:

```bash
python app.py
```

Open the local URL printed by Flask, normally:

```text
http://127.0.0.1:5000/
```

The app expects `templates/index.html` to exist. Its frontend should send a JSON `POST` request to `/translate` with a `text` field.

Example request body:

```json
{
  "text": "Good morning. How are you?"
}
```

Example response shape:

```json
{
  "translation": "..."
}
```

The actual Tamil translation is generated by the model and may vary. Empty input returns an error response.

## Run the Jupyter notebook

Install Jupyter if it is not already installed:

```bash
python -m pip install notebook
```

Start Jupyter from the project folder:

```bash
jupyter notebook
```

Open `translation(1).ipynb` and run the cells from top to bottom. The notebook loads the same NLLB-200 model and tests it with an example English sentence.

## Model and language codes

- Model: `facebook/nllb-200-distilled-600M`
- Source language: `eng_Latn` (English)
- Target language: `tam_Taml` (Tamil)

The first model load may take time and requires an internet connection. Later runs may use the locally cached model files.

## Troubleshooting

- **`TemplateNotFound: index.html`** — make sure `index.html` is inside the `templates` folder beside `app.py`.
- **Missing package errors** — activate the project virtual environment and install the dependencies listed above.
- **Model download or connection errors** — check your internet connection and try loading the model again.
- **Transformers API errors** — confirm that the installed Transformers version matches the notebook's pinned version (`4.46.3`).
- **Slow first startup** — the model is downloaded and initialized when the Flask app starts, so the first run can take longer.

## GitHub notes

Do not commit virtual environments, Python cache files, secrets, or large downloaded model caches. Keep your source code, notebook, HTML template, and static frontend files in the repository. Review notebook outputs before publishing if they contain personal or sensitive information.
